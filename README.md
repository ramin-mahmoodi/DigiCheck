# شکارچی و اعتبارسنج تخفیف‌های دیجی‌کالا (Digikala Deal Verifier)

> **یک ابزار متن‌باز، سریع و هوشمند برای شناسایی تخفیف‌های واقعی از تخفیف‌های الکی/صوری در پیشنهادهای شگفت‌انگیز دیجی‌کالا با تحلیل چارت تغییرات قیمت.**

این پروژه کاملاً استاتیک طراحی شده و **۱۰۰٪ روی GitHub Pages** بدون نیاز به هیچ سرور خارجی یا دیتابیس میزبانی می‌شود.

---

## 🌟 ویژگی‌های کلیدی

1. **تفکیک کامل دسته‌بندی‌ها (بدون ادغام):**
   - پیشنهادهای شگفت‌انگیز اصلی (`incredible_products_list`)
   - پیشنهاد برق‌آسا (`lightening_deal_products`)
   - پیشنهادهای روز (`deal_of_the_day_products`)
   - شگفت‌انگیزهای در حال اتمام (`running_out_incredible_products`)
   - سوپرمارکتی دیجی‌کالا جت (`fresh_incredible_products`)
   - به‌زودی در شگفت‌انگیز (`teasing_incredible_products`)
   - فیلتر بر اساس دسته‌بندی موضوعی کالاها (موبایل، کالای دیجیتال، مد و پوشاک، خانه و آشپزخانه و...)

2. **الگوریتم هوشمند تحلیل چارت قیمت دیجی‌کالا (`/price-chart/`):**
   - 🟢 **تخفیف ۱۰۰٪ واقعی (کف قیمت ماه):** قیمت شگفت‌انگیز فعلی، ارزان‌ترین قیمت ثبت‌شده در ۳۰ روز اخیر یا در کل تاریخچه است.
   - 🟢 **تخفیف منصفانه:** قیمت کمتر از میانگین یک ماه گذشته و ارزان‌تر از روز قبل است.
   - 🔴 **تخفیف صوری (باد کردن قیمت پایه):** قیمت خط‌خورده (RRP) را اخیراً به طور مصنوعی افزایش داده‌اند تا درصد تخفیف بزرگ و فریبنده به نظر برسد!
   - 🔴 **تخفیف الکی (قیمت ثابت):** کالا در روزهای گذشته نیز با همین قیمت فروخته می‌شده و عملاً تخفیفی داده نشده است.
   - 🔴 **گران‌تر از روزهای قبل:** قیمت فعلی شگفت‌انگیز حتی از قیمت روز قبل هم گران‌تر است!

3. **چارت تعاملی با Recharts:**
   - نمایش خط قیمت فروش و خط‌چین قیمت مصوب (RRP) همراه با خط کف قیمت ۳۰ روزه.
   - محاسبه امتیاز صداقت تخفیف از ۱۰۰.

4. **بخش استعلام دستی هر کالای دلخواه:**
   - امکان وارد کردن هر لینک دیجی‌کالا (مثلاً `https://www.digikala.com/product/dkp-4545846/`) یا کد محصول (`4545846`) برای استعلام آنی چارت و بررسی صحت تخفیف.

5. **میزبانی ۱۰۰٪ رایگان روی GitHub Pages:**
   - به‌روزرسانی خودکار با GitHub Actions هر ۳ ساعت یک‌بار.

## 🛠️ تکنولوژی‌های به‌کاررفته

- **React 18** + **TypeScript**
- **Vite 6** (با مسیردهی نسبی برای گیت‌هاب پیجز)
- **Tailwind CSS** (طراحی مدرن، فارسی، فونت وزیرمتن و Dark Mode)
- **Recharts** (رسم چارت‌های تعاملی قیمت)
- **Lucide Icons**
- **Python 3** (اسکریپت دریافت و تحلیل چارت‌ها)
- **GitHub Actions** (کران جاب خودکار و استقرار در GitHub Pages)

## 🚀 نحوه اجرای لوکال (روی سیستم خودتان)

۱. شبیه‌سازی ریپازیتوری یا رفتن به پوشه پروژه:
```bash
cd digi-deal-verifier
```

۲. نصب پکیج‌ها:
```bash
npm install
```

۳. اجرای اسکریپت دریافت و تحلیل تخفیف‌های زنده دیجی‌کالا:
```bash
python scripts/fetch_and_analyze.py
```

۴. اجرای سرور توسعه فرانت‌اند:
```bash
npm run dev
```
سپس مرورگر را باز کرده و آدرس `http://localhost:3000` را مشاهده کنید.

## 🌐 نحوه استقرار روی GitHub Pages (مرحله‌به‌مرحله)

۱. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً با نام `digi-deal-verifier`).
۲. کدهای این پوشه را پوش کنید:
```bash
git init
git add .
git commit -m "Initial commit of Digi Deal Verifier"
git branch -M main
git remote add origin https://github.com/<نام_کاربری_شما>/digi-deal-verifier.git
git push -u origin main
```
۳. در صفحه ریپازیتوری در گیت‌هاب:
   - وارد **Settings** -> **Pages** شوید.
   - در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** بگذارید.
۴. تمام! ورک‌فلو موجود در `.github/workflows/deploy.yml` به طور خودکار اجرا شده و سایت شما را روی آدرس زیر منتشر می‌کند:
```text
https://<نام_کاربری_شما>.github.io/digi-deal-verifier/
```
هر ۳ ساعت نیز گیت‌هاب اکشنز به صورت خودکار داده‌ها و چارت‌ها را با آخرین تخفیف‌های شگفت‌انگیز به‌روز می‌کند!
